# csv-cleaner

A small command line tool that cleans messy CSV files. It fixes column names, extra spaces,
date and phone formats, and email case, and it removes duplicate rows. Rows it isn't sure
about stay in the output and go into a separate issue report, so nothing disappears
without a trace.

> This is a demo project for my portfolio, not client work. The sample data is synthetic.

## What it does

- **Column names.** `" E-mail Address "` becomes `e_mail_address`. Repeated names get a
  suffix (`name`, `name_2`).
- **Whitespace.** Trims every cell and collapses double spaces.
- **Dates.** Reads `2026-03-04`, `2026/03/04`, `04.03.2026`, `03/04/2026`, `Mar 04, 2026`
  and a few more, and writes ISO dates (`2026-03-04`). Slash dates are read in US order.
  Dotted and dashed dates are read day first, or month first with `--month-first`.
- **Phones.** `(212) 555-0142`, `212.555.0142` and `0012125550142` all become
  `+12125550142`. Ten-digit numbers get the country code from `--country` (default `1`).
- **Emails.** Trimmed and lowercased. Values that are not an email are reported.
- **Duplicates.** Rows with the same `--key` value (case-insensitive) are removed, and the
  report says which row each one duplicated.
- **Report.** One line per problem: row number in the input file, column, value, and what
  is wrong.
- **Input.** Comma, semicolon, tab, or pipe delimiter is detected. UTF-8 (with or without
  a BOM) and Windows-1252 are read without extra flags.
- **Output.** `.csv` (with a BOM, so Excel shows accented letters) or `.xlsx` with a bold,
  frozen header row.

## How to run

You need Python 3.11 or newer.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python -m csv_cleaner samples/customers_dirty.csv -o output/customers_clean.xlsx \
    --dates signup_date --phones phone --emails e_mail \
    --required customer_id,e_mail --key customer_id
```

Column names in the options are the cleaned names (`Signup Date` becomes `signup_date`).
Run `python -m csv_cleaner --help` for every option.

## Sample data

`samples/customers_dirty.csv` is generated by `scripts/make_sample.py` with a fixed seed.
Names come from short made-up lists, emails use the reserved `example.com` domain, and
phone numbers use the `555-01xx` range that is set aside for fiction.
